# Construction Cost Estimator (CCE)

A web-based Construction Cost Estimator designed to help users calculate estimated construction costs based on project specifications, location, and material prices. The system provides a fast and user-friendly way to generate cost estimates while reducing manual calculations.

## 🚀 Features

- User Registration & Authentication
- Construction Cost Estimation
- Location-Based Cost Analysis
- Material Cost Management
- Detailed Cost Breakdown
- Responsive User Interface
- MySQL Database Integration
- AI-Assisted Cost & Time Prediction (FYP Feature)

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript (ES6+)
- HTML5
- CSS3

### Backend
- Python
- flask

### Database
- MySQL

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/construction-cost-estimator.git
cd construction-cost-estimator
```

### 2. Setup Frontend

```bash
cd frontend
npm install
npm run dev
```

### 3. Setup Backend

```bash
cd backend

python -m venv venv

# Windows
venv\Scripts\activate

pip install -r requirements.txt

python run.py
```

### 4. Setup Database

Create a MySQL database and update the database configuration in the backend.

```sql
CREATE DATABASE cce;
```

Import the provided SQL schema into MySQL.

## 💻 Usage

1. Start the MySQL server.
2. Run the Python backend.
3. Run the React frontend.
4. Open the application in your browser.
5. Enter construction project details and generate an estimated cost report.
